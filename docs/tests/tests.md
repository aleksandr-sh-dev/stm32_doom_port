# Testing Environment

Testing is performed using [Ceedling](https://github.com/ThrowTheSwitch/Ceedling).

## Getting Started

- Install Ceedling gem

```bash
gem install ceedling --no-document
```

> [!TIP]
> Set Ruby directory in your PATH
> ```bash
> echo 'export PATH="/home/username/.local/share/gem/ruby/3.3.0/bin:$PATH"' >> ~/.bashrc
> source ~/.bashrc
> ```
